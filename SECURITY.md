# Security Policy

## Supported Versions

Only the latest `main` branch / upcoming release is supported with security updates.

## Reporting a Vulnerability

Please do not publicly report vulnerabilities in the GitHub issues tracker. Do not post PoC code or details of the vulnerability in public.

To report a vulnerability, please use GitHub's **Private Vulnerability Reporting** mechanism:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.
4. Fill out the details securely.

### What to Include
When reporting a vulnerability, please include:
- A description of the issue.
- The steps to reproduce the vulnerability.
- A proof-of-concept (PoC) if applicable.
- The impact of the vulnerability.

## Expected Response Process
We will attempt to acknowledge receipt of your vulnerability report within 72 hours and provide a timeline for the fix and public disclosure via a GitHub Security Advisory.
